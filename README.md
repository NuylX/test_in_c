# 🧪 Test_in_C — Laboratório de Linguagens

Test_in_C é um repositório de **experimentação e aprendizado contínuo em múltiplas linguagens**, com foco inicial em **C**.

![Linguagens](https://img.shields.io/badge/Linguagens-C%20|%20C%2B%2B%20|%20Java%20|%20Python%20|%20C%23-blue)
![Status](https://img.shields.io/badge/Status-Em%20Desenvolvimento-green)

---

## 📘 Objetivo Geral

> Aprender, comparar e aplicar conceitos fundamentais de programação em diferentes linguagens, testando sintaxes, lógicas e boas práticas.

### Metas:
- 🧩 Explorar paradigmas e estruturas básicas de cada linguagem  
- ⚙️ Comparar desempenho e legibilidade  
- 💡 Criar desafios práticos e pequenos projetos  
- 📈 Evoluir gradualmente o nível de complexidade  
- 🤝 Permitir futuras contribuições e benchmarks entre linguagens  

---

## 🗂️ Estrutura do Repositório

Cada linguagem possui sua própria pasta e um `README.md` dedicado com seus experimentos e anotações:

| Linguagem | Diretório | Nível Atual | Descrição |

| 🐍 **Python** | [`/Python/`](Python/) | ⚪ *Futuro aprendizado*  | Scripts rápidos, lógica e automação |
| 💻 **C#** | [`/C#/`](C#/) | ⚪ *Futuro aprendizado* | Foco em aplicações desktop e sintaxe moderna |

## ⚙️ Como Executar os Testes

Cada linguagem possui instruções próprias no seu respectivo `README.md`.  
Exemplo para **C**:

### 🔧 Compilar e Executar no Windows (PowerShell)
```powershell
gcc basico/dados_pessoais.c -o basico/dados_pessoais.exe
.\basico\dados_pessoais.exe
```

### 🔧 Compilar e Executar no Linux / macOS
```
gcc basico/dados_pessoais.c -o basico/dados_pessoais
./basico/dados_pessoais
```
